# AI_Swarm_Hackathon_2026

Project site: [`docs/index.html`](docs/index.html). It is a single page that summarizes the problem, methods and results of the Swarm Atlas and the Swarm Investigator. It also covers the AI Village goal-adoption side study.

## Publish with GitHub Pages

1. Go to **Settings → Pages**.
2. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
3. Pick the branch `claude/busy-planck-eginkl` and the folder `/docs`, then save.

The site will be at `https://eyang111.github.io/AI_Swarm_Hackathon_2026/`.

To preview it locally, open `docs/index.html` in a browser. It has no build step and no external dependencies.
