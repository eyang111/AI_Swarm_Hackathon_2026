Definition, scale and method

Graded progression

Highest level each episode reaches. Level 0 episodes are aggregates: agents converged without influencing each other. A swarm can be temporary; level 5 needs self-organized coordination serving an identifiable collective goal, not long life.

Timeline

One bar per episode, from first to last message. Each dataset has its own time axis because they cover different periods. Click a bar to open it.

Goal relation × consequence for people

Whether the collective goal supports, ignores or works against the agents’ assigned tasks does not decide whether it helps or harms people. An episode can show more than one relation, so rows can add up to more than the episode count.

The five necessary features

How many episodes meet each necessary feature. A full swarm needs all five; the collective goal can be inferred from behavior rather than stated.
